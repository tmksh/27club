プロジェクト概要

THE 27 CLUB — エンターテインメントクラブ ウェブサイト ライブパフォーマンス・イベント・キャスト紹介・WEB予約を提供するクラブ施設のウェブサイト。 React + Vite によるSPAで構築し、Supabaseでイベント・キャスト情報を動的管理。 管理者はログイン不要のデモモード、またはSupabase認証によりコンテンツをCMS的に編集可能。
項目内容
サービス名THE 27 CLUB
種別クラブ施設 コーポレートサイト + CMS管理画面
対応言語日本語 / 英語（LanguageContextによるトグル切替）
対応デバイスPC / スマートフォン（レスポンシブ対応）
総ページ数15ページ（一般：13、管理：2）
フォーム機能WEB予約フォーム、お問い合わせフォーム（Netlify Forms）
動的コンテンツイベント一覧、キャスト一覧（Supabase連携）

管理画面（スタッフ向け）

2ページ
アクセス方法 Supabase設定済みの場合：Supabase Auth（メール+パスワード）でログイン。 未設定のデモモード：admin@27club.com / admin123 でログイン（localStorage保存）。
🔐
管理ログイン
/admin/login
  • メール + パスワード入力フォーム
  • Supabase Auth 連携ログイン
  • デモモード：admin@27club.com / admin123
  • ログイン失敗時エラーメッセージ表示
  • ログイン成功後 /admin/dashboard にリダイレクト
  • /admin → /admin/login に自動リダイレクト
🗂️
管理ダッシュボード
/admin/dashboard
  • 認証セッション確認（未ログインは自動リダイレクト）
  • タブ切替：「イベント管理」「キャスト管理」
  • ログアウト機能（Supabase / localStorage 両対応）
  • ログインユーザーメール表示
📅
イベント管理
ダッシュボード内タブ
  • 一覧表示：表示順（display_order）でソート
  • 新規作成：フォームをモーダル表示
  • 編集：既存データをフォームに反映して編集
  • 削除：確認ダイアログ付き
  • 並び替え：ドラッグ＆ドロップ（react-beautiful-dnd）
  • 公開/非公開切替：is_published トグル
  • フォーム入力項目：
  • 　タイトル（日本語 / 英語）
  • 　開始・終了日時
  • 　キャッチコピー・説明文
  • 　料金・料金備考
  • 　予約URL
  • 　メイン画像アップロード（Supabase Storage）
  • 　公開フラグ
🌟
キャスト管理
ダッシュボード内タブ
  • 一覧表示：表示順でソート
  • 新規作成 / 編集 / 削除
  • 並び替え：ドラッグ＆ドロップ
  • フォーム入力項目：
  • 　名前（日本語 / 英語）
  • 　プロフィール画像アップロード（Supabase Storage）
  • 　画像縦位置調整スライダー（image_position_y: 0〜100）
  • 　プロフィール文・特徴・好きなドリンク・ショー紹介
  • 　誕生日・出身地・趣味・特技
  • 　Instagram / Twitter / TikTok URL
  • 　公開フラグ（is_active）

インフラ・環境設定

🚀
Netlify（ホスティング）
  • ビルドコマンド: npm run build
  • 公開ディレクトリ: dist/
  • SPA対応（全パスを index.html にリダイレクト）
  • Netlify Forms — 予約フォーム・お問い合わせフォーム受信
  • フォーム通知先メール: Netlifyダッシュボードで設定
  • プラグイン: @netlify/plugin-emails
🛢️
Supabase（BaaS）
  • 認証: Supabase Auth（メール+パスワード）
  • データベース: PostgreSQL
  • ストレージ: images バケット（画像アップロード）
  • 環境変数（.env）：
  • 　VITE_SUPABASE_URL
  • 　VITE_SUPABASE_ANON_KEY
  • 未設定の場合: デモモード（モックデータ）で動作
📁
マイグレーション
  • ファイル: supabase/migrations/20241114000000_initial_schema.sql
  • events テーブル定義
  • casts テーブル定義
  • インデックス作成
  • updated_at 自動更新トリガー
  • 新環境への適用: Supabase SQL Editor でファイルを実行
📦
開発環境セットアップ
  • Node.js 必須
  • npm install — 依存パッケージインストール
  • npm run dev — 開発サーバー起動（localhost:5173）
  • npm run build — 本番ビルド
  • npm run storybook — Storybook（localhost:6006）
  • .env.local に Supabase 環境変数を設定して起動
