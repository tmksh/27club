SP版FVの news の位置調整

TOPページタイトル縮小

各セクションタイトル（Explore、Floor Map、Access、About This Venue）のフォントサイズを
レスポンシブに設定。SP版では text-3xl、タブレットでは text-5xl、PCでは最大 90px まで。
Playfair Display フォントによるイタリック・斜め表示のデザインを採用しています。

PC Exploreセクション タイトル表示
SP Exploreセクション タイトル表示（縮小版）
レスポンシブクラス: text-3xl md:text-5xl lg:text-7xl xl:text-[90px]
斜めタイトル: rotate(±5deg) skewX(±5deg) の変形を適用
サブテキストもSP/PC間でサイズを差別化 text-xs md:text-xl lg:text-2xl

フロアマップをクリックしたら画像部分に飛ぶようにする

フロアマップ上の座席エリアをクリックすると、下部の座席詳細情報（画像 + 料金表）部分へ
スムーズスクロールで移動するように実装。useRef と scrollIntoView を使用。

PC インタラクティブフロアマップ
SP フロアマップ（モバイル表示）
detailRef を座席詳細エリアに設定し、scrollIntoView({ behavior: "smooth", block: "start" }) で遷移
座席クリック → 座席画像 + 料金表（WEEKDAY/WEEKEND）が表示
初回マウント時はスクロールを抑制（isInitialMount ref使用）
各座席エリア（VIP, V1-V6, PINK, BLUE, STANDING）がクリック可能
