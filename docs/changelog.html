9. Instagram Graph API 連携対応

FVニュースのInstagram連携をBasic Display APIからGraph API（v25.0）に刷新。

  • src/lib/instagram.js をFacebook Graph API v25.0ベースに書き換え
  • ビジネスアカウント・FB連携済みアカウント向けにエンドポイント変更
  • VITE_INSTAGRAM_BUSINESS_ACCOUNT_ID を新たに追加
  • セットアップヘルパー関数を追加（discoverBusinessAccountId、exchangeToken、getPageAccessToken）
  • ページトークン（無期限）取得フローをコメントで明記

10. FV デザインリニューアル

ファーストビューのロゴ・テキストレイアウトをDONUTSサイト参考にリデザイン。

  • 背景に「THE 27 CLUB」大型テキストをうっすら表示（グラデーション透過）
  • メインテキストを「WELCOME TO SHOWTIME」に変更、一文字ずつ下から出現するアニメーション実装
  • サブコピー「最高の夜を届けるナイトクラブ -THE 27 CLUB-」を追加
  • フォントサイズを clamp() で全画面幅に対応するレスポンシブ設定に変更
  • 単語単位でグループ化し、モバイルで変な折り返しが起きないよう修正
  • ニュースカードを1:1（aspect-square）に変更し、Instagramの正方形投稿に対応
  • ニュースカードサイズ・間隔・pbをレスポンシブ調整し、テキストとの重なりを解消
  • 暗めオーバーレイ追加でテキスト視認性向上
