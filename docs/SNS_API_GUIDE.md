# SNS API連携ガイド（Web制作者向け）

ホームページにSNS投稿を自動表示するためのAPI連携について、各プラットフォームの要件・設定方法・費用をまとめました。

---

## 📸 Instagram（おすすめ・一番よく使われます）

### できること
- Instagramの投稿（画像・キャプション・投稿日など）をホームページに自動で表示
- 新しく投稿すると、HP側も自動で更新

### 必要なもの（先方にお願いすること）

| 項目 | 詳細 |
|------|------|
| Instagramアカウント | **ビジネスアカウント** または **クリエイターアカウント** が必要 |
| Facebookページ | 上記Instagramと連携済みであること |

> ⚠️ **注意**: 個人アカウントのままでは利用できません

### APIの発行方法

#### 手順概要
1. [Meta for Developers](https://developers.facebook.com/) にログイン
2. 「マイアプリ」から新しいアプリを作成
3. アプリタイプで「ビジネス」を選択
4. 「Instagram Graph API」を追加
5. Instagramアカウントを紐付け
6. アクセストークンを発行

#### 詳細手順
```
1. developers.facebook.com にFacebookアカウントでログイン
2. 右上の「マイアプリ」→「アプリを作成」
3. ユースケース: 「その他」を選択
4. アプリタイプ: 「ビジネス」を選択
5. アプリ名を入力（例: 〇〇会社HP連携）
6. 左メニュー「製品を追加」→「Instagram Graph API」をセットアップ
7. 「設定」→「基本設定」でアプリシークレットを確認
8. グラフAPIエクスプローラーでアクセストークンを生成
9. 必要な権限: instagram_basic, instagram_content_publish, pages_show_list
```

### 費用

| 項目 | 費用 |
|------|------|
| API利用料 | **無料** |
| 運用コスト | なし（通常利用範囲） |

### 注意点
- 🔐 セキュリティ上、APIキーはサーバー側で安全に管理
- 🔄 約**60日に1回**、トークンの更新が必要
  - 自動更新の設定も可能（Long-Lived Token使用）
- 📊 レート制限: 1時間あたり約200リクエスト

## 📺 YouTube（いちばん簡単・安定）

### できること
- YouTubeチャンネルの最新動画を自動でHPに表示
- 再生回数、いいね数、コメント数の取得

### 必要なもの

| 項目 | 詳細 |
|------|------|
| YouTubeチャンネル | 通常のものでOK |
| Googleアカウント | チャンネル管理者のもの |

### APIの発行方法

#### 手順概要
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. 新しいプロジェクトを作成
3. 「APIとサービス」→「APIライブラリ」
4. 「YouTube Data API v3」を検索して有効化
5. 「認証情報」からAPIキーを発行

#### 詳細手順
```
1. console.cloud.google.com にログイン
2. 左上「プロジェクト選択」→「新しいプロジェクト」
3. プロジェクト名を入力（例: company-website）
4. 作成後、「APIとサービス」→「ライブラリ」
5. 検索欄に「YouTube Data API v3」と入力
6. 「有効にする」をクリック
7. 「認証情報」→「認証情報を作成」→「APIキー」
8. 生成されたAPIキーをコピー
9. （推奨）「キーを制限」でHTTPリファラー制限を設定
```

### 費用

| 項目 | 費用 |
|------|------|
| API利用料 | **無料**（1日10,000ユニットまで） |
| 追加費用 | 通常のHP利用では上限に達することはほぼなし |

> 💡 **クォータ目安**: 動画一覧取得 = 1ユニット、動画詳細取得 = 1ユニット
> 一般的なHP表示（10動画程度）なら1日数十ユニット程度

### 特徴
- ✅ 審査なし
- ✅ 実装が簡単
- ✅ トラブルが少ない
- ✅ ドキュメントが充実

👉 **YouTubeはAPI連携が一番おすすめです**

## 🐦 X（旧Twitter）

### できること
- 投稿内容・画像・いいね数などをHPに表示
- ハッシュタグ検索、タイムライン取得

### APIについて

| プラン | 費用（月額） | 主な機能 |
|--------|-------------|----------|
| Free | **$0** | 書き込みのみ（読み取り不可）、1,500投稿/月 |
| Basic | **$100** | 読み取り可、10,000投稿取得/月、50,000投稿取得/アプリ/月 |
| Pro | **$5,000** | フル機能、100万投稿取得/月 |
| Enterprise | 要問合せ | 大規模利用向け |

> ⚠️ **2023年以降の仕様変更**: 無料プランでは投稿の読み取りができなくなりました

### 実務上の判断

コストが高いため、多くの場合は**埋め込み表示（Embed）**を使用します。

```html
<!-- 埋め込み例 -->
<blockquote class="twitter-tweet">
  <a href="https://twitter.com/ユーザー名/status/ツイートID"></a>
</blockquote>
<script async src="https://platform.twitter.com/widgets.js"></script>
```

#### Embedのメリット
- 無料で利用可能
- 実装が簡単
- 公式のデザインで表示

#### Embedのデメリット
- 自動更新ができない（手動でHTMLを更新）
- デザインのカスタマイズに制限

## 🎵 TikTok

### できること
- 動画投稿をHPに表示
- ユーザー情報の取得

### APIについて

| 項目 | 詳細 |
|------|------|
| 公式API | あり（TikTok for Developers） |
| 審査 | あり・制限が多め |
| 仕様変更 | 頻繁に発生 |
| Display API | 動画埋め込み用（比較的使いやすい） |

### 発行手順（概要）
1. [TikTok for Developers](https://developers.tiktok.com/) に登録
2. アプリを作成
3. 必要なAPIを申請（審査あり）
4. 承認後、アクセストークン取得

### 実務上の判断

安定運用が難しいため、**Embed（埋め込み）対応が一般的**です。

```html
<!-- TikTok埋め込み例 -->
<blockquote class="tiktok-embed" 
  cite="https://www.tiktok.com/@ユーザー名/video/動画ID"
  data-video-id="動画ID">
</blockquote>
<script async src="https://www.tiktok.com/embed.js"></script>
```

## 🔧 技術的な実装について

### サーバーサイドでの実装が必要な理由
- APIキーの保護（クライアントサイドに露出させない）
- レート制限の管理
- キャッシュによるパフォーマンス最適化

### 推奨技術スタック
- **サーバー**: Node.js / PHP / Python
- **キャッシュ**: Redis / Memcached / ファイルキャッシュ
- **更新頻度**: 5〜15分間隔でAPI取得、キャッシュ保存
